# "寻根溯源"族谱管理系统 - 文件结构说明

## 1. 项目概述

**项目名称**: 寻根溯源 - 族谱管理系统  
**项目类型**: Qt5 桌面应用程序  
**数据库**: PostgreSQL  
**编程语言**: C++17  
**目标**: 实现族谱的创建、管理、查询与分析功能

## 3. 代码文件详细说明

### 3.1 数据模型类

| 文件 | 类名 | 职责 |
|------|------|------|
| `include/User.h`<br>`src/User.cpp` | User | 用户数据模型。存储用户ID、用户名、邮箱、注册时间等属性 |
| `include/Person.h`<br>`src/Person.cpp` | Person | 族谱成员数据模型。存储成员姓名、性别、生卒年、辈分、所属族谱等属性 |
| `include/Genealogy.h`<br>`src/Genealogy.cpp` | Genealogy | 族谱数据模型。存储谱名、姓氏、修谱时间、创建者等属性 |
| `include/Family.h`<br>`src/Family.cpp` | Family | 家庭数据模型。存储丈夫ID、妻子ID、结婚年份等属性，表示一对夫妻及其子女 |

### 3.2 核心管理类

| 文件 | 类名 | 职责 |
|------|------|------|
| `include/DatabaseManager.h`<br>`src/DatabaseManager.cpp` | DatabaseManager | **数据库管理器（单例模式）**。提供所有数据库操作接口，包括用户管理、族谱管理、成员管理、家庭关系查询、祖先追溯、后代查询、关系查找等核心功能 |

### 3.3 UI组件类

| 文件 | 类名 | 职责 |
|------|------|------|
| `include/MainWindow.h`<br>`src/MainWindow.cpp` | MainWindow | **主窗口**。应用程序主界面，包含菜单栏、工具栏、状态栏，管理所有子组件，协调用户交互 |

| `include/DashboardWidget.h`<br>`src/DashboardWidget.cpp` | DashboardWidget | **仪表盘组件**。显示族谱统计信息，包括成员总数、性别比例、辈分分布等 |
| `include/GenealogyManager.h`<br>`src/GenealogyManager.cpp` | GenealogyManager | **族谱管理器组件**。提供族谱的创建、编辑、删除、邀请用户协作等功能 |

## 4. 数据库文件说明

### 4.1 schema.sql - 数据库架构

定义完整的PostgreSQL数据库结构：

| 内容 | 说明 |
|------|------|
| **表结构** | users、genealogies、user_genealogy、families、persons 共5张表 |
| **索引** | 为高频查询字段创建索引（姓名模糊搜索、辈分、族谱ID等） |
| **触发器** | 自动维护辈分(trg_person_generation)、验证出生年份(trg_verify_birth_years) |
| **存储过程** | sp_get_spouse_and_children、sp_get_ancestors、sp_get_descendants、sp_find_relationship |
| **视图** | v_person_details、v_children |

### 4.2 queries.sql - 核心SQL查询

包含所有实验要求的SQL查询语句：

| 查询编号 | 功能 | 说明 |
|----------|------|------|
| 1 | 查配偶及所有子女 | 使用UNION合并配偶和子女查询 |
| 2 | 递归追溯祖先 | 使用Recursive CTE向上追溯 |
| 3 | 递归追溯后代 | 使用Recursive CTE向下追溯 |
| 4 | 平均寿命最长一代 | 按辈分分组计算平均寿命 |
| 5 | 50岁+无配偶男性 | 使用NOT EXISTS子查询 |
| 6 | 早于辈分平均出生年 | 使用窗口函数/子查询 |
| 7 | 亲缘关系查询 | 双向BFS查找最近公共祖先 |
| 8-11 | 性能测试与统计 | 索引测试、模糊查找、辈分统计、男女比例 |

### 4.3 csv_data/ - 数据文件

用于批量导入/导出的CSV数据文件：

| 文件 | 记录数 | 说明 |
|------|--------|------|
| users.csv | 20 | 用户账号数据 |
| genealogies.csv | 12 | 族谱基本信息 |
| user_genealogy.csv | ~25 | 用户-族谱关联关系 |
| persons.csv | 100,000+ | 族谱成员数据 |
| families.csv | ~30,000 | 家庭数据 |

| 文件 | 用途 |
|------|------|
| `CMakeLists.txt` | CMake构建配置。定义Qt5依赖、项目源文件、编译选项等 |

### 6.1 config.ini 配置文件格式

首次运行程序时，会在可执行文件所在目录自动生成 `config.ini` 配置文件，格式如下：

```ini
[Database]
Host=localhost
Port=5432
Name=family_genealogy
User=postgres
Password=123456
```

可以根据实际环境修改配置文件中的连接参数。

## 8. 程序启动流程

```
1. main.cpp
   ├── 初始化QApplication
   ├── 配置PostgreSQL数据库连接
   ├── 创建/检查数据库
   └── 创建MainWindow并显示

2. MainWindow构造函数
   ├── setupUi() - 初始化UI组件
   ├── createMenuBar() - 创建菜单栏
   ├── createToolBar() - 创建工具栏
   ├── createStatusBar() - 创建状态栏
   └── showLoginDialog() - 弹出登录对话框

3. 用户登录成功后
   ├── onLoginSuccess() - 处理登录成功
   ├── 显示主界面各Tab组件
   └── 用户可操作族谱、成员、查询等功能
```

## 9. 数据库表关系图

```
┌─────────────┐       ┌──────────────────┐       ┌─────────────┐
│   users     │──1:N──│  user_genealogy  │──N:1──│ genealogies │
└─────────────┘       └──────────────────┘       └──────┬──────┘
                                                        │
                                                        │ 1:N
                                                        ▼
                                                 ┌───────────┐
                                                 │ persons   │
                                                 └─────┬─────┘
                                                       │
                              ┌────────────────────────┤
                              │                        │
                              ▼                        │
                        ┌───────────┐                  │
                        │ families  │                  │
                        └─────┬─────┘                  │
                              │                        │
                              │ 1:N (子女出生家庭)       │
                              └────────────────────────┘
```

**表关系说明**：
- `persons` 表通过 `birth_family_id` 字段引用 `families` 表，表示该成员出生于哪个家庭
- `families` 表通过 `husband_id` 和 `wife_id` 引用 `persons` 表，表示家庭中的夫妻关系
- 所有表都有 `genealogy_id` 字段关联到 `genealogies` 表
