## 一、实体及其属性

### 1. 用户（User）
| 属性 | 类型 | 说明 |
|------|------|------|
| user_id | INT (PK) | 用户唯一标识 |
| username | VARCHAR(50) | 登录名，唯一 |
| password_hash | VARCHAR(255) | 密码哈希 |
| email | VARCHAR(100) | 邮箱，可选 |
| created_at | TIMESTAMP | 注册时间 |

### 2. 族谱（Genealogy）
| 属性 | 类型 | 说明 |
|------|------|------|
| genealogy_id | INT (PK) | 族谱唯一标识 |
| name | VARCHAR(100) | 谱名 |
| surname | VARCHAR(50) | 姓氏 |
| compile_time | DATE | 修谱时间 |
| description | TEXT | 简介，可选 |
| creator_id | INT (FK) | 创建者，引用 User |

### 3. 成员（Person）
| 属性 | 类型 | 说明 |
|------|------|------|
| person_id | INT (PK) | 成员唯一标识 |
| name | VARCHAR(100) | 姓名 |
| gender | CHAR(1) | 性别（'M'/'F'） |
| birth_year | INT | 出生年份 |
| death_year | INT | 卒年，NULL 表在世 |
| biography | TEXT | 生平简介 |
| generation | INT | 辈分（根为 1，子+1） |
| genealogy_id | INT (FK) | 所属族谱 |
| birth_family_id | INT (FK) | 出生家庭，NULL 表未知 |

> **为什么增加 `generation`？** 虽然可通过递归计算，但存储冗余辈分字段能极大加速“同辈统计”、“平均寿命最长的一代”等分析查询。  
> **为什么增加 `birth_family_id`？** 将一个人直接关联到其出生的家庭，可以瞬间向上找到其父母（家庭中的丈夫/妻子），从而让递归向上追溯祖先的 CTE 变得非常简单。

### 4. 家庭（Family）
| 属性 | 类型 | 说明 |
|------|------|------|
| family_id | INT (PK) | 家庭唯一标识 |
| husband_id | INT (FK) | 丈夫，引用 Person |
| wife_id | INT (FK) | 妻子，引用 Person，可为 NULL（单亲） |
| genealogy_id | INT (FK) | 所属族谱 |
| marriage_year | INT | 结婚年份，可选 |

> 一个家庭记录一次婚姻（或单亲单位）。允许多个家庭存在（支持再婚/一夫多妻），一个人可以出现在多个家庭的 husband_id 或 wife_id 中。

### 5. 用户-族谱关联（User_Genealogy）
这是用户与族谱的多对多联系产生的关系实体，用于记录邀请协作。

| 属性 | 类型 | 说明 |
|------|------|------|
| user_id | INT (FK) | 用户 |
| genealogy_id | INT (FK) | 族谱 |
| role | VARCHAR(20) | 角色，如 'creator' / 'editor' |
| joined_at | TIMESTAMP | 加入时间 |

主键为 (user_id, genealogy_id)。

---

## 二、联系类型汇总

| 联系 | 参与实体 | 类型 | 说明 |
|------|----------|------|------|
| 创建 | User → Genealogy | **1 : N** | 一个用户创建多个族谱，一个族谱必须有一个创建者（creator_id）。 |
| 协作 | User ↔ Genealogy | **M : N** | 通过 User_Genealogy 关联，一个用户可参与多个族谱，一个族谱可有多个协作用户。 |
| 包含 | Genealogy → Person | **1 : N** | 一个族谱包含多个成员，一个成员只属于一个族谱。 |
| 丈夫 | Person → Family | **1 : N** | 一个人可以作为多个家庭的丈夫，一个家庭只有一个丈夫（husband_id 可为 NULL）。 |
| 妻子 | Person → Family | **1 : N** | 一个人可以作为多个家庭的妻子，一个家庭只有一个妻子（wife_id 可为 NULL）。 |
| 出生 | Person → Family | **N : 1** | 一个人通过 birth_family_id 关联其出生的家庭（亲生父母家庭），一个家庭可以有多个子女。 |
